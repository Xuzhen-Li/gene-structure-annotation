# 分支怎么选（结构）

## 择一主草稿（不要混称）

| 条件 | 选 | 引擎印象 |
|------|-----|----------|
| 有近缘、已整理参考 GFF | **S11** | Liftoff / LiftOn / CAT |
| RNA + 蛋白，无近缘参考 | **S1** | BRAKER4/3 + StringTie 对照 |
| 几乎只有蛋白 | **S2** | GALBA / GeMoMa |
| 很深 Iso-seq | **S3** | IsoQuant / SQANTI（± EviAnn） |
| 要 GPU 无证据对照 | **S13** | Helixer / Tiberius / ANNEVO（对照，非偷换） |
| 经典 EVM/PASA | **S14** | `docs/steps/dclab/` |
| 证据极薄 | **S6** | 暂定稿，METHODS 写 L0 |
