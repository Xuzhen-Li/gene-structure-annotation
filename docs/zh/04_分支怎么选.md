## 为什么

1. **证据决定方法**（Ji / Freedman）— 见 [14](14_为什么这样选证据.md)。  
2. **主草稿只能有一个称呼** — 叠加支（S5/S10…）不是第二条主路。  
3. **S13 是对照** — 有 RNA+蛋白时禁止静默顶替 S1。  
4. **近缘好 GFF → 先 S11** — 投影再补洞，通常优于从零 invent。  
5. 拿不准且有 RNA+蛋白 → **S1**，降低选择瘫痪。

**反例：** 同时交 Helixer 与 BRAKER，METHODS 却只写「S1」。
