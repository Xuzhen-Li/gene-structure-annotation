# 外部软件流程教程与会议

英文索引（链接齐全）：[`../TUTORIALS_AND_MEETINGS.md`](../TUTORIALS_AND_MEETINGS.md)

## 为什么要看外面的教程？

仓库教你**选哪条路、怎样算合格**；Galaxy / 会议材料教你**软件怎么点、小数据集上长什么样**。  
两边一起用：先 flow 工具出 plan，再拿 GTN 练手感。

## 软件流程教程（结构）

| 教程 | 练什么 | 对应我们 |
|------|--------|----------|
| Galaxy BRAKER3 | RNA+蛋白 → 结构注释 → BUSCO/OMArk → 浏览 | **S1** |
| Galaxy Helixer vs BRAKER3 | 两套结果对比 | **S1 + S13 对照**（禁止无声替换） |
| Galaxy RepeatMasker（BRAKER 前置） | mask 素养 | **A0** |
| Harvard FAS How to annotate a genome | 证据思维 | 选支 / ROADMAP |
| NCBI EGAPx | 公共 EGAPx 包 | **S8 对照** |

注意：GTN 示例常是**小型真菌**基因组，和植物 T2T 数字不可硬比。

## 会议：JOBIM 2026 结构注释小会

- 主题：真核基因**结构**注释还难不难；长读长 RNA；Helixer / Tiberius / ANNEVO 等 AI ab initio  
- 入口：https://pepi-ibis.inrae.fr/node/136  
- 关键 take-home（Legeai 等）：Helixer **容易过召**、短外显子；Tiberius/ANNEVO 往往更好；EGAPx ≠ RefSeq且依赖 RNA 库；难基因仍要人工或组合器  

这就是我们坚持 **S13 = 对照车道**、有 RNA 时不能用 Helixer 偷换 S1 的会议侧依据。

## 为什么（短）

- 只看论文方法段不够，要看**失败案例**（会议幻灯片常有）。  
- 只看 Galaxy 通关也不够，没有本仓的**选支与验收**会在真实基因组上翻车。
