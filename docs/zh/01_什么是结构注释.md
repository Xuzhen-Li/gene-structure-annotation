# 什么是基因结构注释？

## 它回答的问题

**基因组上，基因在哪里？**

具体来说：外显子、内含子、CDS（编码区）的坐标；常常还有转录本（mRNA）和 UTR。

```text
一长串 DNA（基因组 FASTA）
        ↓  结构注释
一张「地图」：gene / mRNA / exon / CDS 画在哪些碱基上（GFF3）
        ↓  翻译 CDS
一袋代表蛋白序列（proteins.faa）— 给质控和下一步功能注释用
```

## 它通常包含什么（教学拆解）

### 1. 地板：重复序列 / TE 处理

基因组里很多是转座元件（TE）和串联重复。  
不做处理就预测基因，容易：

- 把 TE 里的开放读框当成基因（基因数爆炸）；或  
- 用 **hard-mask（改成 N）** 把真基因附近的序列也毁了（如部分抗病基因 NLR）。

所以结构流程里要先 **soft-mask**（重复区改成小写，碱基还在）。  
TE 可以单独做成项目；在基因结构流程里，它主要是 **A0 的输入纪律**。  
详见：[02_TE与基因的关系.md](02_TE与基因的关系.md)。

### 2. 墙体：基因模型预测

按你手里的**证据**选一条主路（不要同时假装走了五条）：

| 证据 | 常见路线 | 在干什么 |
|------|----------|----------|
| 近缘物种已有很好的 GFF | S11 liftover | 先把坐标搬过来，再补洞 |
| RNA-seq + 蛋白库 | S1 BRAKER + StringTie 对照 | 用证据训练/预测，并用转录本对照 |
| 几乎只有蛋白 | S2 GALBA 等 | 同源映射，少吹完整 UTR |
| 很深的 Iso-seq | S3 | 以长读长证据为骨 |
| GPU、证据很薄 | S13 | **对照**用；有 RNA 时不能偷换掉 S1 |
| 经典 PASA→EVM | S14 | 组合器路线 |

### 3. 装修与验收：合并、质控、人工难位点

- 多套草稿 → 合并（EVM/TSEBRA 等）  
- AGAT 数基因；从 GFF **重新**抽蛋白  
- 蛋白 BUSCO（必须写清谱系名）+ PSAURON 等分诊  
- 难位点 / 串联家族（如 NLR）人工看或明确写「暂缓」  
- 打上 `RELEASE_TAG`，放出 GFF + proteins + METHODS

## 明确不是什么

| 不是 | 那是谁的事 |
|------|------------|
| 只做 TE 文库、LAI、panEDTA | TE 专题（[vitis-te](https://github.com/Xuzhen-Li/vitis-te) / 实验室 `03_TE`） |
| GO / KEGG / 结构域 / 基因可读名 | [gene-function-annotation](https://github.com/Xuzhen-Li/gene-function-annotation) |
| 把功能表写回 GFF 第 9 列 | 目前两仓都**不宣称**已自动完成 |

## GFF 里常见层级（认地图）

| 特征 | 含义 |
|------|------|
| `gene` | 一个基因座 |
| `mRNA` | 一条转录本（可以有多 isoform） |
| `exon` | 外显子 |
| `CDS` | 编码区（翻译用它） |
