# S2 / S3 / S13 / S14 速览（其他草稿支）

完整对照：[`../ROADMAP.md`](../ROADMAP.md)。这里只建立直觉，不替代英文 SCENARIOS。

## S2 — 几乎只有蛋白

| | |
|--|--|
| **证据** | 蛋白库；RNA 很少或没有 |
| **引擎** | GALBA / GALBA2 / GeMoMa |
| **诚实边界** | 少吹「完整 UTR / 全转录本」；同源映射擅长 CDS，弱于精细剪接 |
| **何时用** | 无 RNA 预算，或 RNA 质量差到不能训 BRAKER |

走完仍回主干：AGAT → 蛋白 → BUSCO+PSAURON → 放行。

## S3 — 很深的 Iso-seq / 长读长证据

| | |
|--|--|
| **证据** | 深度 Iso-seq 或证据型 CDS |
| **引擎** | IsoQuant → SQANTI3（± EviAnn）+ BRAKER 补孤儿 |
| **关键** | **SQANTI 过滤不能省**；长读长噪声也会造假模型 |
| **何时用** | 长读长是主证据，Illumina RNA 只是辅 |

## S13 — GPU / 薄证据 ab initio **对照**

| | |
|--|--|
| **引擎** | Helixer / Tiberius / ANNEVO（± SegmentNT 观察名单） |
| **角色** | **对照轨**，用来找漏检、冲突位点 |
| **红线** | 有 RNA+蛋白时，**禁止**静默用 S13 顶替 S1（EVALUATION 自动不合格） |
| **已知坑** | Helixer 可过召短无支持外显子 → AGAT 基因数虚高（JOBIM 2026） |

教学口诀：S13 是「第二双眼睛」，不是「新主引擎」。

## S14 — 经典 PASA → EVM 组合器

| | |
|--|--|
| **路径** | PASA → Augustus/GeneMark → EVM → polish |
| **文档** | [`../steps/dclab/`](../steps/dclab/) |
| **何时用** | 实验室已标准化 EVM 权重；或要与历史项目对齐 |
| **不是** | 「每个基因组都必须走」的唯一真道 |

## S6（顺带一句）

证据极薄、允许暂定稿 → S6，METHODS 写 **L0 / provisional**。不要把 S6 包装成论文终稿。
