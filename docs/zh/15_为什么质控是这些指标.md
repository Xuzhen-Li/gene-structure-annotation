# 为什么质控是这些指标？

> WHY 深课。操作表见 [06](06_质控课.md) · [11](11_验收L0L1L2.md)；权威 [`../EVALUATION.md`](../EVALUATION.md)。

## 1. 为什么单靠 BUSCO 会失败？

BUSCO 蛋白模式问的是：**保守单拷贝直系同源**在你的基因集里完不完整。  
它**几乎看不见**：

| 盲区 | 为何 BUSCO-C 仍可能好看 |
|------|-------------------------|
| TE 假基因爆炸 | 假基因不占那些直系同源 |
| 串联家族塌缩（NLR 等） | 不在 BUSCO 集合里 |
| 剪接错 / 碎裂 / 邻位融合 | 局部错误；C 未必立刻崩 |
| Helixer 过召短外显子 | 基因数虚高，C 可仍高 |

因此 L1 硬门槛是 **G6（BUSCO）+ G7（PSAURON + 优先表）**，不是「C≥某魔法数字」。  
**反例：** 「C=97%，合格」——优先表空着、串联窗未审，G7 仍失败。

## 2. 为什么必须写谱系全名？

`C=95%` 在 `eukaryota_odb10` 与 `viridiplantae_odb12` 上**不可比**。  
谱系错了：植物留在真核默认、动物用植物库 — 百分比无意义，G6 直接不合格。

教学要求：METHODS / qc 快照写全名（如 `viridiplantae_odb12`），并与组装 Asm1 声明一致。

**反例：** 两篇论文都报「BUSCO 95%」，谱系不同却横比「谁的注释更好」。

## 3. 为什么还要 PSAURON / OMArk？

| 工具 | WHY |
|------|-----|
| **PSAURON** | 给「像不像真基因」打分 → **排序**难位点进优先表；不是第二套直系同源真理 |
| **OMArk** | 从基因家族一致性/完整性换角度看膨胀、污染、缺失；**L2/S5 必做**，L1 植物/T2T 强烈建议 |
| **AGAT counts** | 合并前后基因/mRNA/CDS 数量 sanity；过召第一眼往往在这里 |

多指标是为了**正交盲区**，不是为了堆软件名。

**反例：** 只跑 OMArk 刷分、不做优先表 curation — 指标在，门禁意图（修最差点）没完成。

## 4. 为什么有 S12 停手规则？

无限打磨 0.1% BUSCO 或剪接口味分歧，边际收益趋零，交付永远不到。  
S12 允许在声明阈值下冻结：优先表空 / C 平台期 / 只剩组合器口味差 / 在追噪声级增益。

**反例：** 为刷 C 从 94.7→94.8 改三个月，却不写冻结理由、也不放行 — 违反交付标准。
