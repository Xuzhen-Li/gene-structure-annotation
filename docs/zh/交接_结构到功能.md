# 交接指针 — 结构 → 功能

英文卡片：[`../HANDOFF_STRUCTURE_TO_FUNCTION.md`](../HANDOFF_STRUCTURE_TO_FUNCTION.md)。

拷到功能仓 `local.env`：

1. **`RELEASE_TAG`** = 结构 `release/<TAG>/` 同名  
2. **`PROTEINS_FA`** = `…/release/<TAG>/proteins.faa`（稳定别名；勿用可能过期的 `WORK_DIR/proteins.faa` 根副本）  
3. **`structure_grade`** = 分开写 `grade=L0|L1|L2` 与 `status=provisional|qualified`（勿写 `status=L1`）；仅 lift / 仅 Helixer → `grade=L0` + `status=provisional`
