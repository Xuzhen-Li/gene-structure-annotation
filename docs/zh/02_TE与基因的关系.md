# TE 与基因结构注释的关系

## 核心关系（一句）

**TE 注释是地板；基因结构注释是墙体。**  
地板没铺好，墙会歪——但地板本身不是楼。

## 为什么基因预测前要管 TE？

预测器（BRAKER、GALBA、Helixer…）会在「看起来像基因」的地方下刀。  
TE 里常有类似 ORF 的片段 → 容易造出假基因。  
同时，一些真基因（尤其抗病相关串联家族）又嵌在重复丰富区 → **不能**简单删成 `N`。

因此基因结构流程要求：

1. 用 **soft-mask**（`-xsmall`）：重复区小写，序列还在。  
2. Soft-mask 用的库必须是 **trusted curatedlib**，不是：  
   - 生 EDTA 粗库整锅端；  
   - 整份 working 库；  
   - 多个 haplotype 的 TElib `cat` + CD-HIT 就当 curatedlib。

实验室四层产品（详见英文 [`../TE_LIBRARY.md`](../TE_LIBRARY.md)）：

| 产品 | 能否当 soft-mask / `--curatedlib` 金标准 |
|------|----------------------------------------|
| Working lib（TEtrimmer+CD-HIT） | 否（整份） |
| Family catalog | 否（目录用） |
| **Trusted curatedlib** | **是** |
| panEDTA combine | 泛基因组 TE 轨道；不是 `cat` 替代 |

口诀：**Dedup ≠ curation。** 基因数因 TE 爆炸时走叠加支 **S10**（remask 再进同一草稿）。
