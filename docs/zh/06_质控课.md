# 质控课：BUSCO 不是唯一分数

英文验收全文：[`../EVALUATION.md`](../EVALUATION.md)

## 为什么「只有 BUSCO」不够

BUSCO 盯的是**保守单拷贝直系同源**完不完整。它**几乎看不见**：

- TE 里冒出来的假基因（基因数爆炸但 C 可能还好看）
- 串联家族塌缩（NLR / stilbene）
- 剪接错、碎裂、邻位融合（见 [`../ERROR_CLASSES.md`](../ERROR_CLASSES.md)）
- Helixer 一类 AI 过召：短外显子堆高基因数，C 未必立刻崩

所以 L1 硬门槛要求：**蛋白 BUSCO + PSAURON 分诊 + 优先位点清单**（G6+G7）。L2/S5 再加 **OMArk**。

## 各工具在教什么

| 工具 | 看什么 | 教学要点 |
|------|--------|----------|
| **BUSCO**（蛋白模式） | C/D/F/M + **谱系名** | 必须写 `viridiplantae_odb12` 这类全名；只报「C=95%」不算数 |
| **PSAURON** | 模型「像不像真基因」的分数 | 用来**排序**难位点，不是直系同源真理 |
| **OMArk** | 基因家族一致性 / 完整性 | **L2/S5 必做**；L1 植物/T2T 强烈建议 |
| **AGAT counts** | gene / mRNA / CDS 个数 | 合并前后对照；Helixer 后数量暴涨要警惕 |

基因组 BUSCO（Asm1）和蛋白 BUSCO（阶段 01）是两道闸：前者决定「值不值得注」，后者决定「这套模型像不像完整基因集」。

## BUSCO 四个字母（记牢）

| 字母 | 英文 | 直觉 |
|------|------|------|
| **C** | Complete | 找到了完整直系同源 |
| **D** | Duplicated（在 C 里） | 完整但多份 — 多倍 / 未 purge / 真实扩张 |
| **F** | Fragmented | 找到了但不完整 |
| **M** | Missing | 没找到 |

高 D 别盲目 purge 单倍型去「刷 C」→ 看叠加支 **S9**。

## L0 / L1 / L2（一句话）

| 等级 | 什么时候能写 |
|------|----------------|
| **L0 暂定** | 证据薄、liftover 未补洞、还有公开 curation 债 |
| **L1 合格** | 默认实验室放行：G1–G8（及适用时 G9）全过 |
| **L2 论文/T2T** | L1 + S5（OMArk + 更深 GSAman + 停手规则） |
