# 验收：L0 / L1 / L2

**先打勾：** [验收勾选表.md](验收勾选表.md)（一行页，判断行不行）。

**权威条文是英文** [`../EVALUATION.md`](../EVALUATION.md)。本页用中文讲清门禁在考什么；写论文 METHODS 时以英文勾选表为准。

## 为什么

1. **等级诚实**：L0/L1/L2 证据与 curation 债不同，不能混称终稿。  
2. 硬门槛（G1–G8/G9）挡住「有 GFF 就宣称合格」。  
3. 软指标按**你的谱系与组装**解读，忌抄绝对阈值。  
4. 自动不合格条款保护最常见科学事故（hard-mask、假 curatedlib、S13 偷换…）。  
5. 结构放行是功能仓的前提 — F0 崩了必须回来。

**反例：** 没做 OMArk 却自称 S5/L2。  

深课：[15_为什么质控是这些指标.md](15_为什么质控是这些指标.md)

## 三档

| 等级 | METHODS 标签 | 何时宣称 |
|------|--------------|----------|
| **L0** | `status=provisional` | 薄证据、生 liftover、curation 债未清 |
| **L1** | `status=qualified` | 默认实验室放行 |
| **L2** | qualified + 注明 S5 | L1 + OMArk + 更深 GSAman |

不要把 L0 叫「论文终稿」；不要没做 OMArk 却自称 S5。

## L1 硬门槛（任一失败 ⇒ 不合格）

| 门 | 在考什么 |
|----|----------|
| **G1** | 组装声明可注（`ASSEMBLY_OK` + Asm1 谱系/N50/倍性） |
| **G2** | Soft-mask + **trusted** TE lib（禁止 hard-mask / 生 EDTA 当金标准） |
| **G3** | 草稿支 ID + 工具版本 |
| **G4** | GFF 通过 gffread/AGAT；记下 gene/mRNA/CDS 数 |
| **G5** | 蛋白从**本轮**放行 GFF 重抽；isoform 政策写明 |
| **G6** | 蛋白 BUSCO：**C + 谱系全名** |
| **G7** | PSAURON + 优先表；最差点已修或显式暂缓 |
| **G8** | `release/<TAG>/` 含 GFF + 蛋白 + METHODS（无私有 BAM） |
| **G9** | 适用时：串联/抗病/QTL 窗口无未审塌缩，或列入 open items |

## 软指标（解读，不伪造全球阈值）

蛋白 BUSCO-C、PSAURON、OMArk、AGAT 计数、StringTie↔BRAKER 冲突表 — 都按**你的谱系与组装**在 Asm1/S5 事先设杠。抄哺乳动物论文的绝对阈值去卡植物，会误判。

## 自动不合格（任何等级）

- Hard-mask 当 soft 喂 BRAKER/GALBA  
- 生 EDTA / 整份 working lib 当 `--curatedlib`  
- 有 RNA+蛋白时用 S13 **静默顶替** S1  
- 在本仓 release 里宣称已做 GO/KEGG（那是功能仓）  
- 私有 reads 进 git / 放行包

F0 蛋白 BUSCO 崩了 → 回结构修，不要用漂亮功能表遮羞。
