# 常见翻车（结构注释）

对照英文自动不合格条款：[`../EVALUATION.md`](../EVALUATION.md)。

## 1. Helixer / S13 过召

**现象：** AGAT 基因数远超近缘物种 × 倍性；许多短外显子无 RNA 支持。  
**原因：** AI ab initio 可堆短无支持外显子（JOBIM 2026）。  
**处理：** S13 只作对照；有 RNA+蛋白时主路仍是 S1。冲突进优先表，不要把 Helixer GFF 直接当 release。

## 2. Hard-mask

**现象：** NLR 等重复区基因消失或截断；或预测器行为诡异。  
**原因：** 重复区变成 `N`，序列没了。  
**处理：** 只用 `-xsmall` soft-mask；已 hard-mask 的基因组不要喂 BRAKER。

## 3. `cat` + CD-HIT 冒充 curatedlib

**现象：** soft-mask 后宿主基因被「重复掉」；或 TE 假基因仍在。  
**原因：** 去重 ≠ 人工门控；Ou panEDTA / 实验室红线禁止幼稚 concatenate。  
**处理：** 只用 **trusted curatedlib**（见 [05](05_softmask与A0.md)、[`../TE_LIBRARY.md`](../TE_LIBRARY.md)）。

## 4. 生 EDTA / 整份 working lib 当金标准

Unknowns、基因片段若经 `--curatedlib` 获 100% 信任 → 抹宿主基因。Working lib 是敏感档案，不是 soft-mask 金标准。

## 5. 用功能表装饰坏 GFF

**现象：** GO/结构域表很漂亮，坐标仍是 TE ORF 或塌缩串联。  
**处理：** 功能仓救不了错误位点。先过结构 L1；F0 崩了回结构。

## 6. 蛋白与 GFF 不同步

改完 GSAman 却忘了重跑 `A3_proteins_from_gff.sh` → BUSCO/FA 评价的是旧序列。

## 7. BUSCO 不写谱系 / 植物留在 eukaryota 默认

百分比不可比；算 G6 失败。

## 8. 只报 BUSCO、不做 PSAURON / 优先表

「C 很高所以合格」→ G7 失败。保守单拷贝好看，串联家族可以一塌糊涂。

## 9. 无限刷 0.1% BUSCO

违反 S12。C 平台期就冻结，把剩余口味分歧写进 METHODS。

## 10. 私有 BAM/FASTQ 推进放行包或 git

法律与复现双重事故。放行包只要 GFF + 蛋白 + METHODS（+ qc 快照）；reads 指 SRA。
