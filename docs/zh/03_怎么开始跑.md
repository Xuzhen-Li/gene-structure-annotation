# 怎么开始跑（结构注释）

> 与中文首页「今天最短路径」一致。flow 是**选路+讲解**，不是一键跑完 BRAKER。

**已有基因组（常见）：** plan 第 1 步常写 Asm0（含 hifiasm 叙事）——那是**清单**，不是命令你重装。设 `ASSEMBLY_OK=yes`，把老师给的 FASTA 指给 `GENOME_FA`。[FAQ](FAQ_入门.md)

**葡萄 / 抗病窗：** 照抄 `answers.example` 时 `plant_tandem_focus` 默认 `false`（通用动物也适用）。葡萄组或要 NLR/串联窗 → 改成 `true`，或直接抄 [`examples/plant_sim/01_vitis_s1_s7/answers.sim.yaml`](../../examples/plant_sim/01_vitis_s1_s7/answers.sim.yaml)。

## 三步

### 1. 告诉工具你有什么证据

```bash
git clone https://github.com/Xuzhen-Li/gene-structure-annotation.git
cd gene-structure-annotation
cp pipeline/flow_tool/answers.example.yaml my_answers.yaml
# 用编辑器改 true/false：有没有 RNA、蛋白、近缘参考、要不要论文档…
# 葡萄抗病窗：plant_tandem_focus: true（否则 Overlays 为空、没有 S7）
python3 pipeline/flow_tool/flow.py --answers my_answers.yaml -o my_plan.md
```

打开 `my_plan.md`：会自动选 **S 支**，并逐步写清  
**输入 → 软件目的 → 流程 → 输出**（教学讲解）。

说明：目前是「选路 + 讲解 + 打印可跑助手」；BRAKER 等仍需你在集群上按打印命令执行（诚实边界，见 [12](12_flow工具怎么用.md)）。

### 2. 填路径

键名以 [`../../config/example.env`](../../config/example.env) 为准（常见：`GENOME_FA`、`GENOME_SOFT`、`RNA_BAM`、`PROTEIN_DB`、`BUSCO_LINEAGE`、`COMPLEASM_LINEAGE`、`TRUSTED_TE_LIB`/`CLEAN_TE_LIB`、`WORK_DIR`、`THREADS`、`PROTEINS_FA`、`RELEASE_TAG`）。水稻等禾本科：`BUSCO`/`Compleasm` 常选 `poales_*`，**不要**默认 eudicots。换作物示例：[植物三种模拟.md](植物三种模拟.md)。

```bash
cp config/example.env config/local.env
# ★ 先把 local.env 里所有 /path/to 改成你可写的真实盘（例如 WORK_DIR="$HOME/annot_work"）
#   未改就 source：WORK_DIR=/path/to/work → mkdir 会 Permission denied
# 勿提交 local.env
set -a && source config/local.env && set +a
# 安全检查：占位路径就停
case "$WORK_DIR" in /path/to*|*/path/to*) echo "先改 WORK_DIR，不要照抄 /path/to"; exit 1;; esac
mkdir -p "$WORK_DIR"/{genome,rna,draft,agat,qc,curated,release}
```

`mkdir` 是你先搭骨架；**输入文件要自己放进去**。脚本只会再建各自输出目录。

**三种「打印」别混：**
1. `my_plan.md` — 选路 + 讲解（主文件）  
2. `flow.py --emit-commands` — plan 里附阶段助手命令草稿  
3. `print_qc_commands.py` — 按验收表打印 QC（可先 `--env config/example.env` 空看样例）  
常见问：[FAQ_入门.md](FAQ_入门.md)

### 3. 按 plan 做到放行

先打勾：[验收勾选表.md](验收勾选表.md)（判断行不行）；细则仍看英文 [`../EVALUATION.md`](../EVALUATION.md)。  
可选打印命令：`python3 pipeline/print_qc_commands.py`（先 `source config/local.env`）。  
默认目标 **L1 合格**；论文/T2T 用 **L2/S5**。

有 RNA+蛋白、又没有近缘完美参考时，默认 **S1**。有近缘好 GFF → **S11** 优先。

## 为什么

1. **先答证据再选路** — 避免无脑开五条草稿却混称一条。  
2. **flow 是选路+讲解**，不是黑盒一键注释（集群差太大）。  
3. **local.env 钉路径** — 可复现比「我记得在哪个盘」重要。  
4. **默认目标 L1** — 没有近缘完美参考时 S1；有则 S11。  
5. Print-first 让你看见将跑的命令，而不是藏在 GUI 里。

**反例：** 跳过 answers.yaml，直接乱改别人的 BRAKER 命令，METHODS 对不上证据。
