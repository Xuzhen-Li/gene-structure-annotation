# 术语表（结构注释教学）

| 术语 | 含义 |
|------|------|
| **GFF3** | 基因特征坐标文件；常见层级 gene → mRNA → exon / CDS |
| **gene** | 一个基因座 |
| **mRNA** | 一条转录本（可有多 isoform） |
| **exon** | 外显子 |
| **CDS** | 编码区；翻译蛋白用它 |
| **UTR** | 非翻译区；同源-only 路线少吹完整 UTR |
| **soft-mask** | 重复区改小写，碱基保留（`-xsmall`） |
| **hard-mask** | 重复区改 `N`；本 playbook 禁止用于 BRAKER/GALBA |
| **trusted curatedlib** | 门控后的 TE 共识库；**唯一**允许的 soft-mask / `--curatedlib` 金标准 |
| **working lib** | TEtrimmer+CD-HIT 后的敏感库；整份不得当 curatedlib |
| **curatedlib** | EDTA `--curatedlib` 参数所信任的库；必须 = trusted |
| **A0 / A0b** | Soft-mask 阶段；A0b 为 ProtExcluder 去宿主污染 |
| **S1…S14** | 草稿或叠加支 ID，见 ROADMAP；**主草稿**与 **overlay** 勿混称 |
| **Asm0 / Asm1** | 组装阶段：Asm0=清单/叙事；Asm1=可注声明（`ASSEMBLY_OK`）；已有 FASTA 勿重装 |
| **A\*** | 流水线助手阶段（A0 soft-mask、A3 蛋白、A5 QC、A6 交接…） |
| **G1…G8** | 结构验收勾选硬门槛条目（≠ S 支号） |
| **数字脚本 01–06** | `pipeline/01_qc…` 等文件名阶段，≠ Gate/S 编号 |
| **softmasked_fraction** | 小写碱基占比；**≠** 基因组 TE% |
| **S5 / S7 / S9** | **overlay**（档位或窗口加码），不是第二条主草稿支 |
| **BUSCO C/D/F/M** | Complete / Duplicated / Fragmented / Missing |
| **谱系（lineage）** | BUSCO odb 名，如 `viridiplantae_odb12`；必须与百分比一起报 |
| **PSAURON** | 模型质量分诊分数；用于排序优先位点 |
| **OMArk** | 基因家族一致性/完整性；L2/S5 必做 |
| **AGAT** | GFF 统计与修复工具集；放行前记 counts |
| **isoform policy** | 一基因一代表蛋白，或保留多 isoform — 必须写明并与 FA 一致 |
| **GSAman** | 人工/半自动难位点策展 |
| **PRIORITY_TSV** | 待策展位点表 |
| **S12** | 停手/冻结规则 |
| **L0 / L1 / L2** | 暂定 / 合格 / 论文·T2T 验收等级 |
| **RELEASE_TAG** | 放行目录名；结构→功能的溯源键 |
| **print-first** | 助手先打印命令，由你在集群执行 — 非一键黑盒 |
| **EVM / TSEBRA** | 多草稿合并器 |
| **Liftoff / LiftOn / CAT** | 参考 GFF 投影到目标基因组（S11） |

英文操作仍以 [`../EVALUATION.md`](../EVALUATION.md)、[`../TE_LIBRARY.md`](../TE_LIBRARY.md)、[`../STAGE_IO.md`](../STAGE_IO.md) 为准。

| Family catalog / 家族目录 | 对 working 再做更严聚类（如 80-80）的代表集；**不是** curatedlib，也勿覆盖 working |
| Trusted（R1≈240 示例） | CDS 门控 + 命名超家族 emit 的结果；见 [18](18_TE流程课_借鉴实验室03_TE.md)；面板金库版本以 emit 为准 |
