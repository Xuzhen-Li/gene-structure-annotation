# miniprot · Spaln (protein-to-genome)

- miniprot (Heng Li): fast protein→genome spliced aligner; inside GALBA2, compleasm, LiftOn, EGAPx options.  
- Spaln: classic sensitive protein/cDNA→genome aligner (often in ProtHint / older BRAKER paths).  
- GenomeThreader / Exonerate: legacy homology aligners still in some MAKER configs.  
- **Our mapping:** evidence tracks for S1/S2/S14; prefer miniprot for large genomes unless a recipe mandates Spaln.
