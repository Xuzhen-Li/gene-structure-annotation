# FINDER

- https://github.com/sagnikbanerjee15/Finder  
- Paper: Banerjee et al. *BMC Bioinformatics* 2021 doi:10.1186/s12859-021-04120-9  
- Automated RNA-Seq → assemblies (PsiCLASS) + BRAKER2 + proteins; UTR-aware; tissue/condition tags; microexon handling.  
- Compared favorably to then-SOTA on shared expression data (BRAKER3 paper also lists FINDER as a peer).  
- **Our mapping:** RNA-heavy alternate to hand-built S1; still rejoin at AGAT/BUSCO/qualify.
