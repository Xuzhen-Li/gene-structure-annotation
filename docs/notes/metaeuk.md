# MetaEuk

- https://github.com/soedinglab/metaeuk  
- Paper: Levy Karin et al. *Microbiome* 2020 doi:10.1186/s40168-020-00808-x  
- Homology-based gene discovery on **eukaryotic metagenomic contigs** (MMseqs2 + exon DP); GFF/protein out; taxonomy helpers.  
- **When:** environmental / MAG-style eukaryotes, not a replacement for chromosome-scale single-genome S1.  
- **Our mapping:** metagenome lane beside the main Asm→S spine; still soft-mask/QC when you have a single long assembly.
