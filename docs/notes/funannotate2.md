# funannotate2

- https://github.com/nextgenusfs/funannotate2  
- Docs: https://funannotate2.readthedocs.io/  
- Flow: `clean` → `train` → `predict` → `annotate`.  
- Built-in FA slice: Pfam, dbCAN, Swiss-Prot, MEROPS, BUSCOlite; GenBank/GFF/proteins out.  
- Addons (https://github.com/nextgenusfs/funannotate2-addons): eggNOG-mapper, InterProScan, antiSMASH, SignalP.

**Adopt:** fungi-first structure peer; after `predict`, either stay in funannotate2 annotate/addons **or** export proteins into gene-function-annotation F1 for a METHODS-aligned FA table.
