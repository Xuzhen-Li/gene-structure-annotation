# Mikado + Portcullis

- Mikado: https://mikado.readthedocs.io/ · Earlham — pick best transcripts from multiple assemblers (ORF/UTR/junction metrics; chimeric split).  
- Portcullis: reliable splice junctions from RNA-seq to feed Mikado.  
- Already named in **S13** (Helixer + Mikado); also useful after multi-assembler short-read stacks (StringTie × N).  
- **Our mapping:** transcript combiner before EVM; not a full ab initio pipeline by itself.
