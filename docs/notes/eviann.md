# EviAnn

- Paper: *Nature Methods* 2026 doi:10.1038/s41592-026-03156-0 — evidence-only annotation (no ab initio).  
- Builds models from RNA-seq assemblies + related-species transcripts/proteins (or UniProt); liftover-capable; traceable evidence per CDS.  
- Reports competitive / better sensitivity-precision than BRAKER3/MAKER2 in their benchmarks when evidence is strong.  
- **Our mapping:** strengthens **S3** (Iso-seq / evidence backbone) and “evidence-first” philosophy; pair with BRAKER orphans when ab initio still needed. Check GitHub/release name on the paper landing page when installing.
