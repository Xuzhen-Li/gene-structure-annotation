# Comparative Annotation Toolkit (CAT)

- https://github.com/ComparativeGenomicsToolkit/Comparative-Annotation-Toolkit  
- Paper: Fiddes et al. *Genome Research* — clade annotation via Progressive Cactus HAL + reference GFFs; optional AUGUSTUS CGP / RNA.  
- Cell/T2T collections often use **CAT + Liftoff/LiftOn** for gene transfer after assembly.  
- **Our mapping:** multi-genome / T2T transfer lane (with Liftoff/LiftOn/TOGA2); needs HAL alignment — not default for a lone de novo genome.
