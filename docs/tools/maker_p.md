# MAKER-P — classical plant annotation engine

**Role:** Copetti Rabiosa-style stack; alternate draft for comparison.

## Get it
https://yandell-lab.org/software/maker-p/ · MAKER wiki.

## Pattern
Species TE lib → RepeatMasker → MAKER-P (EST/RNA + proteins + SNAP/Augustus) → separate ncRNA/TE products.

Prefer BRAKER3/GALBA for new *Vitis* work unless your site standard is MAKER-P; if both exist, AGAT+BUSCO compare before merge.
