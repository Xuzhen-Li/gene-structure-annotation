# 知识单元

[English](README.md) · [首页](../../README.zh.md) · [知识地图](../KNOWLEDGE_MAP.zh.md)

知识单元是讲一个概念或一组判据的短页面。书章是长文；单元只写要点，并为每一句给出来源和读了什么。单元的版式与 TE-Lib 一致。

## 单元的版式

1. **是什么**：用几句话说明概念。
2. **证据的结构**：证据或产物的种类，通常用表。
3. **怎样认出**：检查文件或报告用的简短现场卡片。
4. **本仓库的默认路线与分支**：只指向流程页面，不抄写。
5. **植物与葡萄中已知的情况**：没有已读来源支持的说法标 **[待确认]**。
6. **论断与来源**：论断、来源、原文引句和读了什么。
7. **相关页面**：书章、其他单元和目录小节。

## 规则

- 判据单元只解释检查测的是什么，并链接到 [`docs/EVALUATION.md`](../EVALUATION.md)；阈值和门槛只写在那里。
- 引句从同一行所列来源原样复制；没有为本单元重新打开来源的，在该行写明。
- **[待确认]** 表示该说法还缺已读来源，补上出处之前不删除。
- 每个单元都有章节相同的中文页；引文保留来源原文的语言。
- 旧页面不移动，列在[旧页面](../KNOWLEDGE_MAP.zh.md#older-pages)。
