# Contributing

Short rules for this repo (structure primary). English public surfaces only.

## Classroom vs cluster

- **Classroom** = `my_plan` / print-first. Finish the plan; do **not** invent `status=L1`.
- `grade=` and `status=` are separate fields. No fake L1.

## Boundaries

- **TE soft-mask is hard** (trusted lib only; A0). Structure is primary.
- Functional annotation (GO/KEGG/names) lives **only** in [`gene-function-annotation`](https://github.com/Xuzhen-Li/gene-function-annotation).
- Full map: [`docs/BOUNDARY.md`](docs/BOUNDARY.md).

## How to work

- Use the [issue templates](.github/ISSUE_TEMPLATE/); open a PR with the checklist.
- Track work on [Annotation Project #2](https://github.com/users/Xuzhen-Li/projects/2).
- Public English. Chinese teaching stays under `docs/zh/` only.
