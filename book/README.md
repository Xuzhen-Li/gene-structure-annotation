# Plant gene structure annotation: a study guide with grapevine as the example

[中文](README.zh.md)

This folder holds a study guide that sits beside the methods catalog in the [repository README](../README.md). It explains the concepts, walks through every step with its tools, papers, labs, tiers and evaluations, and ends with choosing tools, pitfalls and quality control, a worked grapevine example and a glossary. It does not replace the README, `docs/` or the pipeline scripts.

The whole text in one file is [`BOOK_full.md`](BOOK_full.md); the same text is split by chapter under [`chapters/`](chapters/). File list, sizes, DOI counts and sha256 are in [`INDEX.md`](INDEX.md). Every statement cites a paper by DOI or a repository file; quotes marked “Authors:” are claims from the tool authors.
