# Chapter 16. Ideas not yet tied to one tool

*This chapter reproduces [README section 15](../../README.md#section-15): the section notes, the full tool table with paper, lab, tier and evaluation, and the benchmark notes. Links point back into the repository.*

Ideas recorded in the 2026-11 survey. Nothing here changes the default path until it is tested.

**Needs:** depends on the idea; nothing here changes the default path until it is tested. [Data needs by scenario](../../README.md#data-needs)

**Clusters:**
- *Workflow rules* (complementary): Soft-mask hand-off rule (idea), Family-window check using function results (idea), Track annotation edit distance (AED) per model, Harmonise models across haplotypes before pangenome PAV. Rules to adopt in this repo's workflow once tested.
- *Known error modes* (complementary): Chimeric mis-annotation survey, Annotation affects orthology (idea). Explain how gene-model errors propagate into orthology and functional analysis.
- *AI-assisted curation* (alternatives): GeneWhisperer, Human-AI collaborative annotation framework. Proposals only; always require human sign-off.
